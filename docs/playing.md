# 新手指南

[项目首页](../README.md) · [Apple Silicon 下载](https://github.com/Nevergoodstudy/sanguosha-zhongduanban/releases/latest)

## 先打一局练习

1. 启动游戏，在主菜单进入「练习局」，按 `Enter` 确认武将。
2. 按手牌上标出的数字选择「杀」，在目标弹窗选择甘宁并确认。观察战斗记录里的「闪」响应。
3. 按 `E` 结束出牌。弃牌弹窗会提示要选几张。用 `Tab` 切换卡牌，按 `Enter` 切换所选状态，再移动到确认按钮完成弃牌。
4. 对手出「杀」时，可选择打出「闪」。自己的回合继续按手牌上显示的数字出牌。
5. 结算后选择「最近战报」查看事件，或选择「再来一局」。

## 身份局

从「开始新游戏」选择 2–8 名玩家、简单／普通／困难 AI，以及固定主公或随机身份。通常按准备、判定、摸牌、出牌、弃牌、结束的顺序推进。判定结果和技能可以改变可以执行的阶段。

| 身份 | 获胜目标 |
|---|---|
| 主公 | 消灭所有反贼和内奸 |
| 忠臣 | 保护主公并与主公同胜 |
| 反贼 | 击败主公 |
| 内奸 | 最后独自存活 |

手牌区显示花色、点数和数字快捷键。部分牌需要目标，距离和装备会影响可选对象。「闪」在响应时使用。结束出牌后，手牌超过体力值时需要弃牌。

## 查看和导出战报

最近战报会在结算后保存，随后可以从主菜单打开。macOS 默认保存在 `~/Library/Application Support/Sanguosha/match_history.json`。可以直接从已安装的入口导出。

```sh
sanguosha --latest-report > report.json
sanguosha --replay report.json --step
```

## 保存与恢复练习局

启动时指定练习局存档，进入练习后会在每回合开始前保存。退出后用同一个文件恢复，退出时尚未打完的回合会重新开始。结算并成功保存战报后会移除这份续局存档。

```sh
sanguosha --practice-save practice.json
sanguosha --resume-practice practice.json
```

## 局域网内测

服务端默认只在本机监听。用三个终端在本机启动服务端和两个客户端。

跨设备内测时，房主把示例中的 `127.0.0.1` 换成本机的局域网地址，保留 `--lan-preview`。另一台设备用房主的局域网地址连接。

```sh
sanguosha --server 127.0.0.1:8765 --lan-preview
sanguosha --connect 127.0.0.1:8765 --name 玩家一
sanguosha --connect 127.0.0.1:8765 --name 玩家二
```

1. 玩家一输入 `create 2`，把显示的房间号告诉玩家二。
2. 玩家二输入 `join 房间号`。两人各输入 `ready`，由房主输入 `start`。
3. 根据各自终端显示的选项输入 `hero 武将ID`。出牌、响应和弃牌时使用当次提示里的编号。

| 命令 | 用途 |
|---|---|
| `play 手牌号 [目标号…]` | 使用指定手牌，按需提供目标 |
| `end` | 结束出牌 |
| `respond [牌号]` | 填写牌号响应，省略牌号则放弃 |
| `discard 牌号…` | 提交本次弃牌选择 |
| `quit` | 退出客户端 |

当前发布的联机验证范围为本机双客户端。项目的实际验证环境和覆盖范围见[实施与验收记录](macos-improvement-plan.md)。
